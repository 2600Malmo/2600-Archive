## October 2026

On 2 October, [@kryssar](https://github.com/kryssar) presented **Intermediate Hacking — One Tunnel, Two Stories**.

The talk follows a controlled lab scenario from a compromised public web server to private application data and a privileged Windows process, then revisits the activity from the defender’s perspective. It explains why network boundaries, application authorization, and software privileges need separate attention.
